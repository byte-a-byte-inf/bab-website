Pedagogia

Formativo vs. Somativo

Tarefas Semanais

Formativo
✓ Sem nota: foco em errar e aprender
✓ Conclusão: ex: 4 de 5 feitas
✓ Tentativas livres: feedback instantâneo
✓ Formato Misto: código + questões objetivas
Zero ansiedade de nota durante o aprendizado

Prova Final

Somativo
✓ Com nota: o único momento formal
✓ Cronômetro: rascunho salvo a cada digitação
✓ Correção rápida: testes ocultos e nota no envio
✓ Auditoria total: código visível para os professores
Avaliação segura aplicada no encerramento da turma
Prática livre durante o mês → Avaliação justa no último sábado
